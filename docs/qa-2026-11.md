# QA notes, November 2026 (v0.1.0)

## Verified by Claude (emulator, Android 16 / API 36)

- Unit tests: Canvas parsing, dedup, reminders, timezones, the capping rule, mail
  cursor and filters, the store round-trip, palettes, and chat parsing. All green.
- Chat Worker: 13 `node --test` tests green. `wrangler deploy --dry-run` accepts the
  config (rate limit of 3 per 60 s).
- Emulator smoke test:
  - A fresh install opens on Settings.
  - Canvas, Courses, Mail, Global chat and Settings all open with no credentials and
    no chat URL, without crashing.
- `MailProviderTest`: the IMAPS provider resolves in the packaged app.
- Release build:
  - Minified with R8 and signed with a throwaway key, it is **1.5 MB** (limit 5 MB).
  - It launches, and a forced tick runs with no crash.
  - The JavaMail IMAP classes survive R8.
- The tick alarm is armed with `setAndAllowWhileIdle`, firing about every 6–10.5
  minutes.
